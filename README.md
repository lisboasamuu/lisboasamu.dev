# lisboasamu.dev

V1 do meu portfolio.

## Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide Icons

## Rotas

- `/` — portfolio principal
- `/projects` — projetos da V1
- `/resume` — recruiter mode com estilos de impressão

## Desenvolvimento

```bash
npm install
npm run dev
```

## Validação

```bash
npm run lint
npm run typecheck
npm run build
```
